# Multimodal Ambulance Detection Using Image Processing and RF433MHz Sensor

## Overview
This project is a smart traffic management system designed to provide priority passage for ambulances at traffic intersections.
The system combines:
* Raspberry Pi 5
* Tesseract OCR
* RF433MHz Communication
* Arduino Uno
to detect ambulances and automatically control traffic signals.

## Features
* Ambulance detection using OCR
* RF433MHz-based emergency vehicle identification
* Automatic traffic signal control
* Real-time response
* Cost-effective and scalable design

## Hardware Components
* Raspberry Pi 5
* Pi Camera Module
* Arduino Uno
* RF433MHz Transmitter
* RF433MHz Receiver
* LEDs
* Buzzer

## Software
* Python
* Tesseract OCR
* Festival TTS
* Arduino IDE
